# Bonfÿre Recipes

**Workflows start with a real input and end with something a person can inspect.**

This repository retains six small, industry-oriented recipe documents originally written for an earlier Bonfÿre command surface. They're useful as workflow patterns and source examples—not a live list of supported plug-and-play automations. The [current Bonfÿre source](https://github.com/Nickgonzales76017/bonfyre), [Aurekai examples](https://aurekai-work-samples.pages.dev/), and [guides](https://docs.aurekai.work/) show the current direction.

These are the **six recipe files currently in this repository**, not a promise of additional vertical folders.

## From pattern to working system

A recipe shows a *proposed sequence*. An operational implementation must also establish the source revision, model and device requirements, permission to access the input, the receiving application's record, and any human approval, payment, or publication obligations.

For current examples that show these boundaries in use, start with [the document workspace](https://aurekai-work-samples.pages.dev/documents/), [shipment handoff](https://aurekai-work-samples.pages.dev/archive/), or [request to books](https://docs.aurekai.work/request-to-books).

The original recipes remain available for reference. Their old command forms, timing estimates, automatic-quality claims and pricing examples should be verified against the current engine before any reuse in a customer environment.
